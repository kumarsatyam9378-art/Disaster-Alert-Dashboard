# Disaster Alert Dashboard

Live disaster monitoring dashboard for earthquakes and weather conditions.

## Features

- Live earthquake data
- Weather monitoring
- Interactive map
- Location watchlist
- AI-powered alert explanation
- Firebase Firestore storage
- Responsive design

## APIs Used

- USGS Earthquake API
- Open-Meteo Weather API
- Open-Meteo Geocoding API
- OpenStreetMap
- OpenRouter AI
- Firebase Firestore

## Tech Stack

HTML
CSS
JavaScript
Leaflet
Firebase
OpenRouter

## Deployment

Deployed using Vercel.
